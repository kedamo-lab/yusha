# YUSHA

Главная — `index.html`, страница TikTok — `clips.html`. Кнопка справа открывает клипы с motion-переходом. На мобильных кнопка находится над кнопкой SERVER. Уменьшение анимаций учитывает настройки системы.

## Локальный запуск

Нужен Node.js 22+. Локальный сервер работает без внешних зависимостей; Wrangler нужен только для Cloudflare.

```powershell
npm run dev
```

Открыть http://127.0.0.1:4173. Проверки: `npm test`.

## TikTok: что работает без подключения API

Настроен реальный профиль [@yusshhik](https://www.tiktok.com/@yusshhik). Вкладка «Профиль TikTok» загружает официальный creator embed: профиль и до десяти последних видео. Доступность зависит от TikTok, публичности профиля, сети и блокировщиков. Ссылки в виджете могут открывать TikTok. Виджет загружается только при открытии вкладки.

Вкладка «Видео» показывает сохранённую подборку из **18 настоящих публикаций @yusshhik**, обновлённую 11 октября 2026 года через официальный Display API. Ролики открываются внутри сайта в вертикальном TikTok-плеере: работают прокрутка, стрелки и закрытие по Escape. На правой кромке плеера есть область для жеста прокрутки, поскольку сам сторонний iframe перехватывает жесты. Список ссылок хранится в `tiktok-videos.json`; этот файл не обнаруживает будущие публикации сам. Без подключённого API локальный сервер обновляет подписи и временные ссылки на обложки через oEmbed с кэшем на 30 минут. Даты, длительность и просмотры в сохранённой подборке соответствуют моменту её выгрузки.

Когда сохранённая подборка недоступна, показывается явно подписанное превью дизайна. Его изображения и подписи не являются публикациями пользователя. Статистика не выдумывается.

Статические страницы можно разместить на GitHub Pages без сборки. На таком хостинге работают переходы, подборка, вертикальные плееры и creator embed; серверный маршрут `/api/tiktok` там отсутствует. Ссылки TikTok на обложки имеют срок действия; для их обновления нужен сервер либо повторное обновление сохранённой подборки. Даже без обложки карточка остаётся доступной по подписи, а плеер загружается непосредственно с TikTok.

## Собственная лента и новые видео

Для автоматического обнаружения новых публикаций, полной истории видео и меток «НОВОЕ» нужна авторизация владельца **@yusshhik** через Login Kit. Для тестирования можно использовать Sandbox без модерации; для production-приложения требуется одобрение TikTok. Добавлены страницы `terms.html` и `privacy.html`: перед указанием их в production их нужно проверить и опубликовать на своём домене.

1. Скопировать `.env.example` в `.env`.
2. Указать `TIKTOK_CLIENT_KEY` и `TIKTOK_CLIENT_SECRET` из своей конфигурации Sandbox или production. Секреты не отправлять в чат и не добавлять в Git.
3. В кабинете добавить Login Kit, разрешения `user.info.basic,video.list,user.info.profile,user.info.stats`, включить Desktop и зарегистрировать Desktop Redirect URI `http://127.0.0.1:4789/callback/`. Desktop используется только для локального подключения владельца; посетителям сайта вход не нужен. В Sandbox также добавить @yusshhik в Target Users.
4. Выполнить `npm run connect:tiktok` и открыть http://127.0.0.1:4789/. Войти как @yusshhik и подтвердить чтение данных. Локальный обработчик проверяет state, cookie, PKCE и username, затем сохраняет токены в `.local/tiktok-token.json`. Токены другого аккаунта не сохраняются. Доступ к статистике можно не предоставлять; базовый профиль, список видео и username нужны для подключения.
5. Перезапустить `npm run dev`. Страница сама переключит сохранённую подборку на актуальную ленту после успешного ответа API.

Если токены уже получены другим способом, можно указать `TIKTOK_ACCESS_TOKEN` и `TIKTOK_REFRESH_TOKEN` в `.env`; `TIKTOK_SCOPES` должен соответствовать фактически выданным разрешениям. Минимальный вариант для ручного подключения — `user.info.basic,video.list`; описание и статистика появляются с дополнительными разрешениями.

Секреты не передаются в браузер и исключены из Git. Обновлённые токены сохраняются в `.local/tiktok-token.json`; при развёртывании эта папка должна находиться на постоянном приватном хранилище. Статический сервер выдаёт только явно разрешённые файлы. Локальный обработчик подключения слушает только 127.0.0.1 и не является публичным маршрутом сайта. Для переподключения выполнить `npm run connect:tiktok` и перезапустить сервер сайта. При ручной смене значений токенов в `.env` прежнее приватное состояние игнорируется.

Проверка новых видео выполняется раз в минуту, пока страница открыта и видима; сервер кэширует ответы на минуту. Новые ID сравниваются с сохранёнными в localStorage данного браузера. При первом посещении текущие ролики считаются исходной лентой, затем новые получают метку до просмотра. Это не фоновое наблюдение при закрытом сайте и не push-уведомления. Доступна загрузка более ранних публикаций по курсору API. При сбое уже загруженные карточки остаются, время успешного обновления не подменяется.

## Облачный сервер

TikTok API развёрнут на Cloudflare Workers Free: https://yusha-tiktok-api.yusha-site.workers.dev/api/tiktok. CORS разрешён для https://yusha-lyart.vercel.app. `tiktok-config.js` использует этот адрес на опубликованном сайте и локальный API при разработке.

`cloudflare/worker.mjs` и `cloudflare/feed.mjs` обслуживают только публичную ленту. SQLite Durable Object хранит обновляемые токены и минутный кэш; состояние переживает перезапуск и повторное развёртывание. Обновления токенов объединяются, чтобы одновременные посетители не запускали несколько ротаций. Ключи приложения и исходные токены переданы в Cloudflare Secrets, в публичную сборку они не входят.

Повторное развёртывание: `npm ci`, `npm run cloud:check`, `npm run cloud:deploy`. Первоначальный перенос уже подключённого локально TikTok: `npm run cloud:secrets`, затем `npx wrangler deploy --secrets-file .local/cloudflare-secrets.json`. Файл секретов игнорируется Git. Исходный токен используется только при первом создании объекта; после ротации приоритет всегда у постоянного хранилища.

Сайт остаётся на Vercel. `npm run build` копирует в `public/` только 15 разрешённых файлов сайта, а `vercel.json` публикует эту папку. Серверный код, `.env`, `.local`, тесты и конфигурация хостинга в статическую сборку не попадают. На тарифе Workers Free действует лимит 100 000 запросов в сутки; платный тариф не включён.

Официальные инструкции: [Sandbox](https://developers.tiktok.com/docs/en/add-a-sandbox), [Login Kit Desktop](https://developers.tiktok.com/docs/en/login-kit-desktop), [Display API](https://developers.tiktok.com/docs/en/display-api-get-started), [Creator Embed](https://developers.tiktok.com/docs/en/embed-creator-profiles), [Embed Player](https://developers.tiktok.com/docs/en/embed-player), [Token Management](https://developers.tiktok.com/docs/en/oauth-user-access-token-management).
