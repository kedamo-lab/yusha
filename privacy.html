Приватность

YUSHA — личный сайт с публичными материалами автора @yusshhik. Для просмотра не требуется вход в TikTok или регистрация на сайте.

Данные TikTok

Владелец @yusshhik может подключить свой профиль через официальный Login Kit. Сервер получает имя, аватар, описание, статистику и список публичных видео в пределах выданных разрешений. Эти публичные сведения отображаются в ленте. Пароль TikTok сайт не получает.

Access token и refresh token хранятся в приватном серверном хранилище и используются только для чтения разрешённых данных и продления доступа. Они не входят в публичные файлы сайта. Автор может отозвать доступ в настройках TikTok; для удаления сохранённых токенов и данных подключения можно обратиться по ссылке ниже.

Данные в браузере

Сайт сохраняет в localStorage идентификаторы известных и непросмотренных роликов, чтобы показывать метки «НОВОЕ». Это состояние остаётся в данном браузере. Его можно удалить, очистив данные сайта в настройках браузера.

Сторонние сервисы

Плееры и виджет профиля загружаются с TikTok. При их загрузке TikTok может обрабатывать IP-адрес, сведения о браузере и cookies согласно своей политике приватности. Сайт размещён на Vercel, сервер ленты и приватное хранилище токенов — на Cloudflare Workers, а шрифты главной страницы загружаются с Google Fonts; эти сервисы получают технические данные запроса согласно своим политикам.
